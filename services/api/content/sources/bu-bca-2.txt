# bca-4-operating-systems | 4 | Operating Systems
## Introduction
### Operating system concepts
= Functions and types of operating systems, system calls and OS structure.
- An OS manages processes, memory, files, devices and security, and provides the user interface.
- Types: batch, multiprogramming, time-sharing, real-time, distributed, mobile.
- System calls are the interface between programs and the kernel (e.g. fork, exec, read, write).
- Kernel designs: monolithic, layered, microkernel.
> Describe the functions and types of operating systems
> Explain how a system call works
## Process Management
### Processes and threads
= Process states, the PCB, context switching and threads.
- Process states: new, ready, running, waiting, terminated.
- The PCB stores a process's state, program counter, registers, scheduling and memory information.
- A context switch saves one process's state and loads another's; it is pure overhead.
- Threads of one process share code, data and files but have their own stack and registers.
> Draw the process state diagram
> Compare processes and threads
### CPU scheduling
= FCFS, SJF, priority and round robin scheduling; waiting and turnaround time.
- Turnaround time = Completion time − Arrival time; Waiting time = Turnaround time − Burst time.
- FCFS can suffer the convoy effect; SJF gives the minimum average waiting time.
- Round robin gives each process a time quantum in turn; good for time-sharing.
- Priority scheduling can starve low-priority processes; aging fixes this.
> Draw Gantt charts and compute average waiting times
> Compare scheduling algorithms
hook: Three people at a photocopier: one has 100 pages, two have 1 page each. Who should go first?
ex: FCFS, all arriving at 0: P1 = 24, P2 = 3, P3 = 3. Waiting: 0, 24, 27; average 17.
ex: SJF order P2, P3, P1: waiting 0, 3, 6; average 3.
q: In round robin with quantum 4, how many turns does a 10 ms process need? || Three (4 + 4 + 2).
terms: burst time; turnaround time; waiting time; Gantt chart
## Synchronisation and Deadlocks
### Process synchronisation
= Race conditions, critical sections, semaphores and classic problems.
- A critical-section solution needs mutual exclusion, progress and bounded waiting.
- A semaphore S is an integer with wait (P: S − 1, block if negative) and signal (V: S + 1).
- Classic problems: producer–consumer, readers–writers, dining philosophers.
> Use semaphores for mutual exclusion
> Explain the producer–consumer problem
### Deadlocks
= Deadlock conditions, prevention, avoidance (Banker's algorithm), detection and recovery.
- Four necessary conditions: mutual exclusion, hold and wait, no preemption, circular wait.
- Prevention breaks one condition; avoidance (Banker's algorithm) grants a request only if the state stays safe.
- Need = Max − Allocation; a safe sequence exists if every process can finish in some order.
> Apply the Banker's algorithm
> State and break the conditions for deadlock
## Memory and File Management
### Memory management and virtual memory
= Contiguous allocation, paging, segmentation and page replacement.
- Paging divides memory into fixed frames and processes into pages; it removes external fragmentation.
- Logical address = (page number, offset); the page table maps pages to frames.
- Page replacement: FIFO, optimal, LRU; FIFO can show Belady's anomaly.
- Thrashing: the system spends more time paging than executing.
> Translate logical addresses with a page table
> Count page faults for FIFO and LRU
### File systems and disk scheduling
= File access and allocation methods, directories and disk scheduling.
- Access methods: sequential, direct, indexed.
- Allocation: contiguous, linked, indexed.
- Disk scheduling: FCFS, SSTF, SCAN, C-SCAN; seek time dominates disk access.
> Compare file allocation methods
> Compute total head movement for disk scheduling algorithms

# bca-5-algorithms | 5 | Design and Analysis of Algorithms | scheme=NEP 2021; year=2023-24
## Algorithm Analysis
### Asymptotic notation and recurrences
= O, Ω and Θ notation, and solving recurrences.
- f(n) = O(g(n)) is an upper bound, Ω a lower bound and Θ a tight bound.
- Master theorem for T(n) = aT(n/b) + f(n): compare f(n) with n^(log_b a).
- T(n) = 2T(n/2) + n gives Θ(n log n); T(n) = T(n/2) + 1 gives Θ(log n).
> Express running times in asymptotic notation
> Solve recurrences with the master theorem
## Divide and Conquer
### Divide and conquer
= Binary search, merge sort, quick sort and Strassen's multiplication.
- Divide the problem, solve subproblems recursively, combine the results.
- Merge sort: T(n) = 2T(n/2) + n = Θ(n log n).
- Strassen's method multiplies matrices in O(n^2.81) using 7 multiplications instead of 8.
> Analyse divide-and-conquer algorithms
> Write recurrences for divide-and-conquer algorithms
## Greedy Method
### Greedy algorithms
= Fractional knapsack, minimum spanning trees and Dijkstra's shortest paths.
- A greedy algorithm makes the locally best choice at each step.
- Fractional knapsack: take items in decreasing order of value per weight.
- Prim's and Kruskal's algorithms find minimum spanning trees; Kruskal adds the cheapest edge that forms no cycle.
- Dijkstra's algorithm finds shortest paths from one source when edge weights are non-negative.
> Solve fractional knapsack problems
> Find minimum spanning trees and shortest paths
## Dynamic Programming
### Dynamic programming
= Overlapping subproblems and optimal substructure; 0/1 knapsack, Floyd-Warshall, LCS.
- DP stores solutions of overlapping subproblems (memoisation or tabulation).
- 0/1 knapsack: K[i][w] = max(K[i−1][w], vᵢ + K[i−1][w − wᵢ]).
- Floyd–Warshall finds all-pairs shortest paths in Θ(n³).
> Formulate DP recurrences
> Solve 0/1 knapsack by a table
## Backtracking and Complexity Classes
### Backtracking, branch and bound, and NP
= N-queens, subset sum, and the classes P, NP and NP-complete.
- Backtracking builds solutions step by step and abandons a partial solution that cannot succeed.
- Branch and bound prunes using bounds on the best possible solution.
- P: solvable in polynomial time; NP: solutions verifiable in polynomial time; NP-complete problems (e.g. SAT, travelling salesman decision) are the hardest in NP.
> Solve N-queens by backtracking
> Explain P, NP and NP-completeness

## Descriptive Statistics
### Measures of central tendency and dispersion
= Mean, median, mode, range, variance and standard deviation.
- Mean x̄ = Σx ÷ n; median is the middle value of sorted data; mode is the most frequent value.
- Sample variance s² = Σ(x − x̄)² ÷ (n − 1); standard deviation s = √s².
- Coefficient of variation = (s ÷ x̄) × 100; lower CV means more consistent.
- R: mean(x), median(x), var(x), sd(x), summary(x), quantile(x).
> Compute summary statistics by hand and in R
> Compare the consistency of two data sets

## Probability Distributions
### Binomial, Poisson and normal distributions
= The common distributions and their R functions.
- Binomial: P(X = r) = nCr pʳ qⁿ⁻ʳ; mean np, variance npq.
- Poisson: P(X = r) = e^(−λ) λʳ ÷ r!; mean = variance = λ.
- Normal: bell-shaped, symmetric about μ; about 68%, 95% and 99.7% of values lie within 1, 2 and 3 σ.
- R functions: dbinom, pbinom, dpois, pnorm, qnorm, rnorm (d density, p cumulative, q quantile, r random).

## Correlation, Regression and Tests
### Correlation and regression
= Karl Pearson's correlation and the least-squares regression line.
- r = Σ(x − x̄)(y − ȳ) ÷ √(Σ(x − x̄)² Σ(y − ȳ)²); −1 ≤ r ≤ 1.
- Regression line of y on x: y − ȳ = b(x − x̄), with b = r × (sᵧ ÷ sₓ).
- R: cor(x, y), lm(y ~ x), summary(model).
> Fit and interpret a regression line in R
> Compute and interpret Pearson's r
### Hypothesis testing
= Null and alternative hypotheses, t-test and chi-square test.
- Reject H₀ when the p-value is below the significance level α (often 0.05).
- t.test compares means; chisq.test tests independence in a contingency table.
- Type I error: rejecting a true H₀; Type II: accepting a false H₀.

## Introduction to AI
### AI, agents and problem solving
= Definitions of AI, intelligent agents and state-space search.
- An agent perceives its environment through sensors and acts through actuators.
- A problem is defined by an initial state, actions, a goal test and path cost.
- The Turing test judges whether a machine's conversation is indistinguishable from a human's.

## Search
### Uninformed and informed search
= BFS, DFS, heuristic search and A*.
- BFS is complete and optimal for unit costs; DFS uses less memory but may not terminate on infinite paths.
- A* expands the node with the lowest f(n) = g(n) + h(n); it is optimal if h never overestimates (admissible).
- Hill climbing can get stuck at local maxima.
> Trace A* on a small graph
> Compare BFS, DFS and heuristic search
## Knowledge Representation
### Logic and knowledge representation
= Propositional and predicate logic, rules and semantic networks.
- Knowledge can be represented by logic, production rules, semantic networks and frames.
- Inference: modus ponens (from p and p → q, infer q); resolution.
- Forward chaining reasons from facts to goals; backward chaining from goals to facts.
> Represent knowledge in logic and rules
> Apply forward and backward chaining
## Machine Learning
### Supervised and unsupervised learning
= Regression, classification, clustering and model evaluation.
- Supervised learning uses labelled data (regression, classification); unsupervised finds structure in unlabelled data (clustering).
- Algorithms: linear regression, decision trees, k-nearest neighbours, naive Bayes, k-means.
- Accuracy = (TP + TN) ÷ total; precision = TP ÷ (TP + FP); recall = TP ÷ (TP + FN).
- Overfitting: a model fits training data but generalises poorly; use train/test splits and cross-validation.
> Choose a learning approach for a problem
> Evaluate a classifier with a confusion matrix
### Neural networks
= Perceptrons, activation functions and multilayer networks.
- A perceptron computes a weighted sum plus bias and applies an activation function.
- Activations: step, sigmoid, ReLU, softmax.
- Multilayer networks are trained by backpropagation and gradient descent.
