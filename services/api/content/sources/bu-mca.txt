# mca-1-mathematical-foundations | 1 | Mathematical Foundations of Computer Science
## Logic and Proofs
### Propositional and predicate logic
= Logical equivalence, inference rules and proof techniques.
- Rules of inference: modus ponens, modus tollens, hypothetical syllogism, disjunctive syllogism, resolution.
- Normal forms: CNF (conjunction of clauses) and DNF (disjunction of conjunctions).
- Proof methods: direct, contrapositive, contradiction, and mathematical induction (base case and inductive step).
> Derive conclusions with rules of inference
> Prove statements by induction
hook: Every program that sorts correctly for n items also works for n + 1 items. Does it then work for every n?
ex: Prove 1 + 2 + … + n = n(n + 1)/2. Base: n = 1 gives 1 = 1.
ex: Step: if true for k, then 1 + … + k + (k + 1) = k(k + 1)/2 + (k + 1) = (k + 1)(k + 2)/2.
q: What does modus tollens infer from p → q and ¬q? || ¬p.
terms: induction; contrapositive; CNF; inference rule
## Relations and Lattices
### Relations, partial orders and lattices
= Equivalence relations, partial orders, Hasse diagrams and lattices.
- An equivalence relation partitions a set into equivalence classes.
- A partial order is reflexive, antisymmetric and transitive; a Hasse diagram draws it without loops or implied edges.
- A lattice is a poset where every pair has a least upper bound (join) and greatest lower bound (meet).
> Draw Hasse diagrams
> Test whether a poset is a lattice
## Combinatorics and Recurrences
### Counting and recurrence relations
= Permutations, combinations, inclusion–exclusion and solving recurrences.
- Inclusion–exclusion: |A ∪ B ∪ C| = Σ|A| − Σ|A ∩ B| + |A ∩ B ∩ C|.
- Linear homogeneous recurrence aₙ = c₁aₙ₋₁ + c₂aₙ₋₂ is solved by roots of r² − c₁r − c₂ = 0.
- Generating functions encode sequences as power series.
> Count with inclusion–exclusion
> Solve linear recurrence relations
## Graph Theory
### Graphs, trees and algorithms
= Connectivity, planar graphs, colouring and spanning trees.
- Euler's formula for connected planar graphs: V − E + F = 2.
- Chromatic number χ(G) is the fewest colours so adjacent vertices differ; planar graphs need at most 4.
- Kruskal's and Prim's algorithms find minimum spanning trees.
> Apply Euler's formula
> Colour graphs and find MSTs
## Automata Basics
### Finite automata and regular languages
= DFA, NFA, regular expressions and their equivalence.
- A DFA has exactly one transition per symbol from each state; an NFA may have several or ε-moves.
- Every NFA can be converted to an equivalent DFA (subset construction).
- Regular expressions, DFAs and NFAs describe the same class: regular languages.
> Design a DFA for a language
> Convert an NFA to a DFA

# mca-1-data-structures-algorithms | 1 | Data Structures and Algorithms
## Analysis of Algorithms
### Asymptotic analysis and recurrences
= Big-O, Ω, Θ, amortised analysis and the master theorem.
- Master theorem for T(n) = aT(n/b) + f(n): compare f(n) with n^(log_b a).
- Amortised analysis averages cost over a sequence of operations (e.g. dynamic array doubling is O(1) amortised per push).
- Space complexity counts extra memory used.
> Analyse algorithms asymptotically
> Use amortised analysis
## Linear Structures
### Stacks, queues, lists and hashing
= Linear data structures and hash tables.
- Stacks (LIFO) and queues (FIFO) via arrays or linked lists; deques allow both ends.
- Hashing maps keys to slots: h(k) = k mod m; collisions resolved by chaining or open addressing (linear and quadratic probing, double hashing).
- Load factor α = n ÷ m; expected search time with chaining is O(1 + α).
> Implement a hash table with collision handling
> Choose a linear structure for a task
## Trees
### Balanced search trees and heaps
= BSTs, AVL trees, B-trees and binary heaps.
- AVL trees keep balance factor in {−1, 0, 1} by rotations (LL, RR, LR, RL); height O(log n).
- B-trees of order m keep nodes at least half full; used in databases and file systems.
- A binary heap supports insert and extract-min in O(log n); heapsort is O(n log n).
> Insert into an AVL tree with rotations
> Build and use a heap
hook: A BST built from sorted input becomes a linked list. How do AVL trees stop that?
ex: Insert 10, 20, 30 into an AVL tree: 10 becomes unbalanced (balance −2, RR case).
ex: A left rotation at 10 makes 20 the root with children 10 and 30.
q: What is the height bound of an AVL tree with n nodes? || O(log n), about 1.44 log₂ n at most.
terms: balance factor; rotation; heap; B-tree
## Graph Algorithms
### Shortest paths and spanning trees
= BFS, DFS, topological sort, Dijkstra, Bellman–Ford and Floyd–Warshall.
- Topological sort orders a DAG's vertices so every edge goes forward (DFS finishing times).
- Dijkstra with a binary heap runs in O((V + E) log V); needs non-negative weights.
- Bellman–Ford handles negative weights and detects negative cycles in O(VE).
> Run shortest path algorithms by hand
> Topologically sort a DAG
## Algorithm Design
### Greedy, dynamic programming and backtracking
= Design paradigms with classic examples.
- Greedy: Huffman coding, activity selection, fractional knapsack.
- Dynamic programming: LCS, matrix chain multiplication, 0/1 knapsack, edit distance.
- Backtracking: N-queens, subset sum, graph colouring; branch and bound for optimisation.
> Choose a design paradigm for a problem
> Write a DP recurrence and fill its table

## Data Modelling

- ER constructs: entities, attributes, relationships, cardinality, participation, weak entities, specialisation and generalisation.
- Mapping: each strong entity to a table; M:N relationships to a separate table with both keys.

## Relational Algebra and SQL
### Relational algebra, calculus and advanced SQL
= Query languages and advanced SQL features.
- Relational algebra operations: σ, π, ∪, −, ×, ⋈, ÷ (division for "for all" queries).
- SQL features: joins, nested and correlated subqueries, views, window functions (ROW_NUMBER, RANK, SUM OVER).

## Normalisation
### Dependencies and normal forms
= Armstrong's axioms, closures, keys and normal forms up to BCNF and 4NF.
- Armstrong's axioms: reflexivity, augmentation, transitivity.
- Attribute closure X⁺ finds all attributes determined by X; X is a superkey if X⁺ contains all attributes.
- BCNF: every non-trivial FD X → Y has X a superkey; 4NF removes non-trivial multivalued dependencies.
> Compute attribute closures and candidate keys
> Decompose relations into BCNF losslessly
## Storage and Indexing
### Indexing and query processing
= File organisation, B+ tree and hash indexes, and query optimisation.
- B+ trees keep all records in leaves linked for range scans.
- Clustered index orders the data file; a table has at most one.
- Query optimisation chooses a plan by estimated cost; push selections down early.
> Choose an index for a workload
> Read a query execution plan
## Transactions
### Concurrency control and recovery
= Serialisability, locking, timestamps and log-based recovery.
- Conflict serialisability is tested with a precedence graph (acyclic means serialisable).
- Strict two-phase locking holds exclusive locks until commit, preventing cascading aborts.
- Write-ahead logging: log records reach disk before data pages; ARIES uses analysis, redo and undo.
> Test a schedule for serialisability
> Explain recovery with write-ahead logging
## NoSQL
### NoSQL databases
= Key-value, document, column-family and graph stores, and the CAP theorem.
- CAP theorem: a distributed system can guarantee only two of consistency, availability and partition tolerance at once.
- BASE: basically available, soft state, eventually consistent.
- Examples: Redis (key-value), MongoDB (document), Cassandra (column-family), Neo4j (graph).
> Choose a NoSQL model for an application
> Explain the CAP trade-off

# mca-1-operating-systems | 1 | Operating Systems
## Processes and Threads
### Process management and scheduling
= Process concept, threads and CPU scheduling algorithms.
- Scheduling criteria: CPU utilisation, throughput, turnaround, waiting and response time.
- Algorithms: FCFS, SJF/SRTF, priority, round robin, multilevel feedback queue.
- User-level vs kernel-level threads; many-to-one, one-to-one and many-to-many models.
> Compute scheduling metrics
> Compare threading models
## Synchronisation
### Synchronisation and deadlocks
= Critical sections, semaphores, monitors and deadlock handling.
- Peterson's solution satisfies mutual exclusion, progress and bounded waiting for two processes.
- Monitors encapsulate shared data with condition variables (wait, signal).
- Deadlock handling: prevention, avoidance (Banker's), detection with recovery, or ignoring (ostrich).
> Solve synchronisation problems with semaphores
> Apply the Banker's algorithm
## Memory Management
### Paging and virtual memory
= Paging, TLBs, demand paging and replacement policies.
- Effective access time with TLB = h(t + m) + (1 − h)(t + 2m) for hit ratio h, TLB time t and memory time m.
- Demand paging loads pages on a page fault.
- LRU and optimal replacement do not suffer Belady's anomaly; FIFO can.
> Compute effective memory access time
> Simulate page replacement policies
## Storage and File Systems
### File systems and disk management
= File system structure, allocation, free-space management and RAID.
- Inodes store file metadata and block pointers (direct, single, double, triple indirect).
- Free space: bitmap or linked list.
- RAID 0 stripes, RAID 1 mirrors, RAID 5 stripes with distributed parity.
> Compute maximum file size with inodes
> Compare RAID levels
## Security and Virtualisation
### Protection, security and virtual machines
= Access control, threats and virtualisation.
- Access matrix implemented as access control lists or capability lists.
- Threats: malware, buffer overflow, privilege escalation, denial of service.
- Hypervisors (type 1 and 2) and containers isolate workloads.
> Design access control for a system
> Explain virtualisation's role in the OS

# mca-2-computer-networks | 2 | Computer Networks
## Network Architecture
### Layered models and performance
= OSI and TCP/IP models, delay and throughput.
- Total delay = processing + queuing + transmission (L/R) + propagation (d/s).
- Bandwidth–delay product = bandwidth × round-trip time.
- Protocol layering gives modularity; encapsulation adds a header per layer.
> Compute delays and bandwidth–delay product
> Map protocols to layers
## Link Layer
### LANs and switching
= Ethernet, MAC addressing, switches and VLANs.
- A MAC address is 48 bits; ARP maps IP addresses to MAC addresses.
- Switches learn MAC addresses and forward frames; VLANs separate broadcast domains.
- Wi-Fi uses CSMA/CA with optional RTS/CTS.
> Explain switch learning and forwarding
> Explain ARP
## Network Layer
### IP, subnetting and routing
= IPv4, CIDR, NAT, IPv6 and routing protocols.
- CIDR a.b.c.d/n: 2^(32−n) addresses, 2^(32−n) − 2 usable hosts.
- NAT maps private addresses (10/8, 172.16/12, 192.168/16) to public ones.
- Intra-domain routing: RIP, OSPF; inter-domain: BGP.
> Subnet an address block
> Compare routing protocols
q: Split 192.168.10.0/24 into 4 equal subnets. What prefix? || /26, with 64 addresses each.
## Transport Layer
### TCP reliability and congestion control
= Sliding windows, flow control and congestion control.
- TCP connection: three-way handshake (SYN, SYN-ACK, ACK); close with FIN.
- Flow control uses the receiver's advertised window.
- Congestion control: slow start (exponential), congestion avoidance (additive increase), multiplicative decrease on loss.
> Trace TCP congestion window growth
> Distinguish flow and congestion control
## Application Layer and Security
### Application protocols and network security
= HTTP, DNS, email, and TLS and firewalls.
- HTTP/1.1 persistent connections; HTTP/2 multiplexes streams; HTTP/3 runs over QUIC (UDP).
- DNS hierarchy: root, TLD, authoritative servers; records A, AAAA, MX, CNAME.
- TLS provides confidentiality and integrity with certificates; firewalls filter packets by rules.
> Trace a web page request end to end
> Explain how TLS secures traffic

### Intelligent agents and search
= Agent types, uninformed and informed search, and adversarial search.
- A* is optimal with an admissible heuristic (never overestimates) and complete in finite graphs.
- Minimax with alpha–beta pruning searches game trees; best-case it examines about b^(d/2) nodes.

## Supervised Learning
### Regression and classification
= Linear and logistic regression, decision trees, SVM and ensembles.
- Linear regression minimises squared error; regularisation (ridge L2, lasso L1) curbs overfitting.
- Logistic regression models P(y = 1) = 1 ÷ (1 + e^(−z)).
- Decision trees split on information gain (entropy) or Gini; random forests and gradient boosting combine many trees.
- SVM finds the maximum-margin hyperplane; kernels handle non-linear data.
> Choose and train a supervised model
> Explain bias–variance trade-off
