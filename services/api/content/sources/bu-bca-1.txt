## Sets, Relations and Functions
### Set operations and relations
= Union, intersection, complement, De Morgan's laws, and properties of relations.
- De Morgan's laws: (A ∪ B)′ = A′ ∩ B′ and (A ∩ B)′ = A′ ∪ B′.
- |A ∪ B| = |A| + |B| − |A ∩ B| for finite sets.
- A relation R on a set A is reflexive if aRa for every a; symmetric if aRb implies bRa; transitive if aRb and bRc imply aRc. A relation with all three properties is an equivalence relation.
> Apply set identities
> Decide whether a relation is an equivalence relation
hook: In a class of 60, 35 like cricket and 30 like football. Can you be sure some like both?
ex: Class of 60: |C| = 35, |F| = 30, |C ∩ F| = 10.
ex: |C ∪ F| = 35 + 30 − 10 = 55, so 60 − 55 = 5 students like neither.
q: If |A| = 20, |B| = 15 and |A ∪ B| = 28, find |A ∩ B|. || 20 + 15 − 28 = 7.
q: Is "is a sibling of" (excluding oneself) an equivalence relation? || No: it is not reflexive.
terms: union; intersection; complement; relation; equivalence relation
### Functions
= One-one, onto and bijective functions, composition and inverse.
- A function f: A → B assigns exactly one element of B to each element of A.
- f is one-one (injective) if f(a) = f(b) implies a = b; onto (surjective) if every element of B has a pre-image; bijective if both.
- Only a bijection has an inverse f⁻¹: B → A.
- Composition: (g ∘ f)(x) = g(f(x)); in general g ∘ f ≠ f ∘ g.
> Classify a function as injective, surjective or bijective
> Find compositions and inverses
## Mathematical Logic
### Propositions and truth tables
= Connectives, truth tables, tautologies and logical equivalence.
- The conditional p → q is false only when p is true and q is false; p → q is equivalent to ¬p ∨ q.
- The biconditional p ↔ q is true when p and q have the same truth value.
- A tautology is true for every assignment of truth values; a contradiction is false for every assignment.
> Build truth tables
> Test whether two statements are logically equivalent
### Quantifiers and counting
= Predicates, universal and existential quantifiers, and the basic counting principles.
- ∀x P(x) is true when P(x) holds for every x; ∃x P(x) when it holds for at least one x.
- Negation: ¬∀x P(x) ≡ ∃x ¬P(x) and ¬∃x P(x) ≡ ∀x ¬P(x).
- Permutations: nPr = n! ÷ (n − r)!; combinations: nCr = n! ÷ (r!(n − r)!).
- Pigeonhole principle: if n + 1 objects go into n boxes, some box holds at least two.
> Negate quantified statements
> Count arrangements and selections
## Matrices
### Matrix operations and determinants
= Types of matrices, addition, multiplication, transpose, determinant and inverse.
- Matrices A (m × n) and B (n × p) can be multiplied; AB is m × p, and in general AB ≠ BA.
- For a 2 × 2 matrix [a b; c d], the determinant is ad − bc.
- A square matrix has an inverse if and only if its determinant is non-zero: A⁻¹ = adj(A) ÷ |A|.
- (AB)ᵀ = BᵀAᵀ; a matrix is symmetric if Aᵀ = A.
> Multiply matrices and find determinants
> Find the inverse of a 2 × 2 or 3 × 3 matrix
## Graph Theory
### Graphs and degrees
= Vertices, edges, degree, and the handshaking lemma.
- Handshaking lemma: the sum of the degrees of all vertices of a graph is twice the number of edges.
- Consequently, every graph has an even number of vertices of odd degree.
- A graph is simple if it has no loops or parallel edges; the complete graph Kₙ has n(n − 1)/2 edges.
> Use the handshaking lemma
> Count the edges of complete and regular graphs
### Euler and Hamilton graphs, and trees
= Euler circuits, Hamiltonian cycles, and the properties of trees.
- A connected graph has an Euler circuit if and only if every vertex has even degree; it has an Euler path (not circuit) if exactly two vertices have odd degree.
- A Hamiltonian cycle visits every vertex exactly once; no simple degree test decides it in general.
- A tree is a connected graph with no cycles; a tree with n vertices has n − 1 edges.
- A spanning tree of a connected graph includes all its vertices with the fewest edges.
> Decide whether a graph has an Euler path or circuit
> Identify trees and spanning trees

= SR, JK, D and T flip-flops, and their use in registers and counters.

### Data structures and algorithm analysis
= Classification of data structures, abstract data types and Big-O notation.
- Linear structures: arrays, stacks, queues, linked lists; non-linear: trees and graphs.
- An abstract data type specifies data and operations, not implementation.

## Arrays, Searching and Sorting
### Searching
= Linear and binary search.
- Linear search checks each element: O(n); works on unsorted data.
- Binary search needs sorted data; it compares with the middle element and halves the range: O(log n).
- mid = low + (high − low) / 2 avoids overflow.
> Implement linear and binary search
> Compare their complexities
q: How many comparisons at most does binary search need for 1,024 elements? || log₂ 1024 = 10, plus one: about 11.
### Sorting
= Bubble, selection, insertion, merge and quick sort.
- Bubble, selection and insertion sort are O(n²); insertion sort is O(n) on nearly sorted data.
- Merge sort divides, sorts and merges: O(n log n) always, but needs O(n) extra space.
- Quick sort partitions around a pivot: O(n log n) on average, O(n²) in the worst case.
- A sort is stable if equal keys keep their relative order (merge and insertion are stable; quick and selection are not).
> Trace each sorting algorithm on an example
> Choose a sort for a given situation
ex: Bubble sort 5 1 4 2, pass 1: 1 5 4 2 → 1 4 5 2 → 1 4 2 5 (largest at the end).

### Stacks
= LIFO stacks, push and pop, and expression conversion and evaluation.
- A stack is last in, first out: push adds to the top, pop removes from the top.
- Overflow: push on a full stack; underflow: pop on an empty stack.
- Uses: function calls and recursion, undo, infix to postfix conversion, postfix evaluation, bracket matching.
- Postfix evaluation: push operands; on an operator pop two, apply, push the result.

### Queues
= Linear, circular and priority queues, and deques.
- A queue is first in, first out: insert at the rear, delete at the front.
- A circular queue reuses freed space: rear = (rear + 1) % size.
- A priority queue serves the highest priority first; a deque allows insertion and deletion at both ends.
> Implement linear and circular queues
> Explain priority queues and deques
## Linked Lists
### Singly, doubly and circular linked lists
= Nodes and pointers; insertion, deletion and traversal.
- A node holds data and a pointer to the next node; the list is reached through a head pointer.
- Insertion and deletion are O(1) once the position is known; access by index is O(n).
- A doubly linked list has next and previous pointers; a circular list's last node points back to the first.
- Linked lists grow dynamically, unlike fixed-size arrays.
> Insert and delete nodes at any position
> Compare arrays and linked lists
## Trees and Graphs
### Binary trees and binary search trees
= Tree terminology, traversals and BST operations.
- A binary tree node has at most two children; a tree of height h has at most 2^(h+1) − 1 nodes (root at height 0).
- Traversals: inorder (L, root, R), preorder (root, L, R), postorder (L, R, root).
- In a BST, left subtree keys < node < right subtree keys; inorder traversal gives sorted order.
- BST search, insert and delete are O(h): O(log n) when balanced, O(n) when skewed.
> Traverse a binary tree in all three orders
> Insert into and delete from a BST
### Graph representation and traversal
= Adjacency matrix and list, BFS and DFS.
- Adjacency matrix uses O(V²) space; adjacency list uses O(V + E).
- BFS visits level by level using a queue; DFS goes deep first using a stack or recursion.
- BFS finds shortest paths (by number of edges) in unweighted graphs.

> Trace BFS and DFS

## Physical Layer
### Transmission media and signals
= Guided and unguided media, bandwidth, and multiplexing.
- Guided media: twisted pair, coaxial cable, optical fibre; unguided: radio, microwave, infrared.
- Optical fibre uses total internal reflection; it has high bandwidth and is immune to electromagnetic interference.
- Multiplexing shares a link: FDM (frequency), TDM (time), WDM (wavelength, for fibre).
- Switching: circuit, message and packet switching.

## Data Link Layer
### Error detection and flow control
= Framing, parity, CRC, and stop-and-wait and sliding-window protocols.
- Single parity detects odd numbers of bit errors; CRC divides by a generator polynomial and appends the remainder.
- Hamming code can correct single-bit errors.
- Stop-and-wait sends one frame per acknowledgement; sliding window (Go-Back-N, Selective Repeat) sends several.
- MAC protocols: ALOHA, CSMA/CD (Ethernet), CSMA/CA (Wi-Fi).

## Network Layer
### IP addressing and routing
= IPv4 addresses, classes, subnetting and routing algorithms.
- An IPv4 address is 32 bits, written as four decimal octets; IPv6 is 128 bits.
- Classful ranges: A 1–126, B 128–191, C 192–223 (first octet); CIDR notation /n gives the network prefix length.
- A /24 network has 2⁸ − 2 = 254 usable host addresses.
- Routing: distance vector (Bellman-Ford, RIP) and link state (Dijkstra, OSPF).
