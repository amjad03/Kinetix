# Zynetix 3D library: open-licence sources (candidate list)

Status: research only. Nothing below has been downloaded or added to the catalogue. Every URL
marked "HEAD 200" was checked on 2026-10-18 with a HEAD request (size from `Content-Length`);
no model file was fetched. Licences were read from the source's own metadata (Smithsonian Open
Access API `usage.access`, NIH 3D entry API `metadata.license`, DataCite `rightsList`, the
Z-Anatomy `License.txt`, NASA's repository terms).

How a new model gets in (unchanged): add a recipe under `packages/kinetix_3d/tool/models/recipes/`
with `sources`, build it with `tool/models` (names, labels in en/hi/kn, cuts), record it in
`docs/licensing/3D_MODELS.md`, and the catalogue is regenerated by `write_catalogue.mjs`. Remote
entries (`RemoteModelInfo`) need our processed GLB + manifest on the model servers and a bundled
thumbnail, so a raw third-party URL cannot be added as a "cloud-only" catalogue entry; no app code
was changed in this step.

(`isa_BP3D_4.0_obj_99.zip` 142.9 MB + `isa_element_parts.txt` 1.1 MB) = **about 185.5 MB**.

(not in git). Processed output is expected at 0.3–2.5 MB per model, about 20–25 MB for all 20,
served as download-on-demand (`remote_models/`), so the app bundle does not grow.

building if space is tight.
