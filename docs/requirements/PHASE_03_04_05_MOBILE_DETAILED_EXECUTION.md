# Mobile Phases — Teacher / Student / Parent

## Shared foundation

- authentication
- session/device management
- push notifications
- offline cache policy
- secure local storage
- deep links
- API client generation/contract validation
- telemetry
- feature flags

## Teacher priority workflows

Today's classes → attendance → lesson/materials → assignment → assessment/marks → student insights → communication → leave/profile.

## Student priority workflows

Today's classes → attendance → learning content → assignments → quiz/exam → results → AI tutor → timetable/calendar → fees/documents.

## Parent priority workflows

Child switcher → attendance → academic summary → assignments → results → fees → timetable/events → notices → teacher communication → transport where enabled.

All mobile actions must respect the same server-side authorization as every other Kinetix client.
