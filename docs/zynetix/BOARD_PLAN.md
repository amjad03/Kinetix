# Zynetix board: production plan (approved Oct 2026)

Brand: the product is **Zynetix** everywhere users see it ("Zynetix AI", "Zynetix dashboard", "Zynetix Teacher/Student/Parent"). Code identifiers and package names (kinetix_*) stay as they are. New UI strings: en/hi/kn ARB entries, say Zynetix.

Flutter is at /opt/flutter/bin (add to PATH). No Android SDK here: Android-only code is unit-tested with fakes; CI (.github/workflows/zynetix-builds.yml) builds APKs and the macOS app. API: services/api (NestJS, vitest; Postgres via `pg_ctlcluster 16 main start`, copy /home/user/Kinetix/services/api/.env, use your own test DB name). ERP dashboard: apps/erp (/zynetix pages).

## Workstreams
- **W1 Brand & demo-readiness:** Zynetix logo (SVG master in design/brand/, app icons for board/teacher/student/parent on Android/macOS/Windows/Linux, in-app logo); all user-visible KINETIX → Zynetix (ARBs, inline strings, macOS PRODUCT_NAME "Zynetix Board", MSIX, Android labels, server AI messages, "KINETIX ERP → …" → "Zynetix dashboard → …"); APKs reach a LAN demo server over http (build flag in the workflow / network config); AI panel: sign-in notice offers the board's own email+password sign-in (button), errors show the server's message instead of always "sign in again"; demo leftovers ("Sample answer (demo)" wording when no key → clear "Connect Claude in the Zynetix dashboard"); fix the 13 failing board tests.
- **W2 AI pen smart ink:** after drawing with the AI pen, a "Did you mean…" chip row appears automatically: shape alternatives, text/math readings, and matching pictures from assets/library (catalog.json tags), diagram templates (kinetix_ink diagram families), animations, 3D models; tap to replace. Works on every platform: on-device recognisers where present, else the board's AI (Claude via /v1/ai/read-board or a new sketch endpoint) labels the sketch. Handwriting-to-text/OCR on macOS/Windows via the server AI. "AI draw": turn a sketch or prompt into a clean SVG diagram (Claude returns SVG) inserted on the board.
- **W3 Lecture capture & media:** recording becomes a shareable MP4/WebM (screen + mic), uploaded to the server, shared to the class by QR/link and visible in teacher/student apps; local video/audio files (USB/Files) in Insert → Videos with annotation; teacher camera in live/hybrid class.
- **W4 Panel platform:** pen overlay that writes over any app (Android overlay service; macOS/Windows always-on-top transparent window) with capture to a board page; panel home/launcher with admin allow-listed apps (Android); OTA updates: dashboard uploads a release (APK/zip, version, channel), boards check, download, install (Android PackageInstaller; desktop: prompt + download).
- **W5 Sharing & integrations:** casting up to 9 screens, any laptop/phone via the browser /cast page (QR on board); import/export Google Drive and OneDrive (OAuth configured in the dashboard), PPTX export of board pages, share notes to Google Classroom and Moodle (LTI/links).

Each workstream: tests for what it adds; flutter analyze + affected tests green; API/ERP typecheck + affected tests green; commit in its own branch; short report.
